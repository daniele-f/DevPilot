# Local MCP Implementation Plan

**Goal:** A user can connect Codex to one local DevPilot project and manage its backlog through actual MCP tools.
**Spec:** docs/superpowers/specs/2026-11-11-local-mcp-design.md
**Architecture:** Shared SQLite workspace service, hashed connection tokens, official MCP HTTP adapter, Angular connection panel.

- [x] Extract shared workspace operations and retain existing API tests.
- [x] Write failing connection/MCP integration tests for read/edit, project isolation, revocation and restart persistence.
- [x] Add connection migration and official SDK MCP endpoint with per-request authorization.
- [x] Add the local-only Connect AI panel, one-time config display/copy, last-use metadata and revocation.
- [x] Verify real SDK client discovery and create/update/note flow, existing tests, and production separation.
- [x] Document user setup and limitations. Review before completion.

Scope decisions follow the user's approval of the recommended local Codex first slice. No hosted integration, public endpoint, OAuth flow, API key provisioning or Supabase development accounts.
