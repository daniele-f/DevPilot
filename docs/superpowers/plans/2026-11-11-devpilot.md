# DevPilot Implementation Plan

> **For agentic workers:** Execute inline using superpowers:executing-plans and test-driven-development.

**Goal:** A persistent, authenticated project backlog with board, list and notes.
**Architecture:** Domain types and validation → Supabase repository → signal store → standalone Angular UI. SQL migration enforces ownership independently of the browser.
**Tech Stack:** Angular 21, TypeScript 5.9, Angular CDK, Supabase, Vitest, Cloudflare Pages.
**Spec:** docs/superpowers/specs/2026-11-11-devpilot-design.md

## Global Constraints

- Five statuses: Ideas, To Do, In Progress, Testing, Done.
- No advanced integrations or simulated persistence.
- Private per-user projects; responsive dark/light interface.

## Review Focus

- A late project response must not replace another project's items.
- Rejected writes must retain the original item and draft.
- Cross-user foreign keys must fail under RLS.
- Archived items must disappear from active views and remain restorable.
- Empty titles and oversized text must fail consistently.
